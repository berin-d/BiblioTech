## 🗂️ Tools & Resources

### 🛠️ Developer & Documentation
- **[DevDocs.io](https://devdocs.io/)** — Fast, offline, and unified API documentation browser combining multiple docs in a single interface.
- **[Anime.js](https://animejs.com/)** — Lightweight JavaScript animation library with a simple API for animating CSS properties, SVG, DOM attributes, and JS objects.
- **[GrapesJS](https://grapesjs.com/)** — Free, open-source HTML builder framework for building drag-and-drop web page editors.
- **[Tailwind CSS](https://tailwindcss.com/)** — Utility-first CSS framework for rapidly building custom user interfaces directly in your markup.

### 🎨 Design & UI/UX
- **[Figma](https://www.figma.com/)** — Collaborative cloud-based interface design tool for vector graphics, prototyping, and UI/UX projects.
- **[Affinity](https://affinity.serif.com/)** — Professional creative suite (Photo, Designer, Publisher) offering high-performance vector design and image editing without subscription.
